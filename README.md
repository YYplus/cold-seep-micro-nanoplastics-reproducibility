# Cold-seep microplastics and nanoplastics reproducibility repository

This repository contains processed data, metadata, and analysis code supporting the manuscript:

**Discrepant responses of abundant and rare taxa to polyethylene microplastics and nanoplastics perturbations in cold seep sediment**

## Purpose

The repository is intended to provide the materials needed to reproduce the main microbial community analyses reported in the manuscript and to address data and code availability requirements during peer review.

## Raw sequence data

The raw sequencing data are available from the NCBI Sequence Read Archive (SRA) under the following BioProject accession numbers:

- **PRJNA839611**
- **PRJNA841697**

Raw sequencing reads are not duplicated in this GitHub repository.
